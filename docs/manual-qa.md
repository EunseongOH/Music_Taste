# 손으로 봐야 하는 것

자동 검사가 못 보는 것만 적는다. CI(`.github/workflows/app-regression.yml`)는 비밀값이
필요 없는 것만 돌린다 — `npm run typecheck`, `npm run check:regression`.

자동으로 도는 것을 여기 옮겨 적지 않는다. 손 검사 목록이 길면 아무도 안 본다.

## 명령으로 도는 것 (사람이 시작만 한다)

| 명령 | 필요한 것 | 무엇을 보나 |
|---|---|---|
| `npm run check:regression` | 없음 | 곡 수 규칙, 같이 소트 이름, 카드 색·배치 |
| `npm run typecheck` | 없음 | 타입 |
| `npm run check:web` | dev 서버(:3100) | 웹 화면 회귀, 공유, 기준 이미지 |
| `npm run check:toss` | dev 서버 + `npm run dev:toss`(:5173) | 토스 빌드가 웹과 같은지 |
| `npm run check:regression:e2e` | dev 서버 + Playwright | 신원, 로그인 후 저장, 하단 가림, 곡 수 일치 |
| `npm run check:db` | `.env.local` (운영 Supabase 키) | 같이 소트하기 DB 권한 경계 |
| `npm run build` / `build:toss` | `.env.local` | 빌드 |

`check:toss` 는 `build:toss` 와 **같이 돌리지 않는다.** vite 빌드가 dev 서버의 모듈
변환을 흔들어서, 제품 문제가 아닌 `@fs/...` 요청 실패로 빨개진다(2026-09-25 확인).

## 사람만 할 수 있는 것

### 로그인 → 저장

세 갈래 모두 `/taste` 에 머물고, 순위가 그대로이며, 저장이 **한 번만** 되고,
내 취향 스페이스에 나타나는지.

- [ ] 게스트 → 최애곡 소트 → 저장하기 → **기존 이메일 계정** 로그인 → 저장
- [ ] 게스트 → 저장하기 → **신규 이메일 가입** → 저장
      (이메일 확인이 켜져 있으면 "메일로 보낸 링크로 확인한 뒤 로그인해 주세요" 가 떠야
       하고, 창이 닫히며 순위를 잃어선 안 된다)
- [ ] 게스트 → 저장하기 → **구글** 로그인 → 저장
- [ ] 게스트 → 저장하기 → **카카오** 로그인 → 저장 (2026-09-25 확인됨)

### 곡 수

- [ ] 아티스트를 열고 앨범이 다 들어올 때까지 둔다
- [ ] 머리말이 "곡 수 확인 중…" → "N Tracks" 로 바뀐다
- [ ] 전체 선택 → 하단 수가 N 과 같다
- [ ] 월드컵 시작 → 실제 후보도 N 이다
- [ ] 곡 몇 개를 빼면 머리말은 N 그대로, 하단만 줄어든다
- [ ] 불러오는 중에 곡을 빼면, 뒤늦게 들어온 앨범이 그 곡을 도로 고르지 않는다

### 같이 소트하기

- [ ] 카카오톡으로 링크를 보내고 받아서 들어간다
- [ ] 익명으로 소트 → 로그인 → 결과가 남아 있고, 참가자 수·관계도·내 노드가 그대로
- [ ] 새로 고침해도 같다

### 앱인토스

- [ ] 실기기(안드로이드·iOS)에서 Spotify 외부 링크가 열린다
- [ ] 아래쪽 고정 버튼이 안전 영역에 가리지 않는다
