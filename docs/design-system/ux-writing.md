# Sortify UX 라이팅 가이드

> 2026-09-15 제정 · 2026-09-21 개정(브랜드 동사 "소트하다"를 줄 세우다·정렬하다 자리에 채택) · 짝 문서: `typography.md`, `dialogs.md`
> 화면에 들어가는 모든 문구(버튼·안내·빈 상태·에러·토스트·공유 문구·메타데이터)에 적용한다.

## 1. 우리가 하는 일

> 우리는 **좋아하는 아티스트가 있는 리스너**에게 **곡을 둘씩 골라 내 순위를 만드는 경험**을 제공해서,
> 리스너가 **"내가 진짜 좋아하는 곡"을 발견하고 나누도록** 한다.
> 이는 Sortify 가 **공유를 통해 새 리스너를 만나는 데** 도움이 된다.

문구는 이 흐름을 방해하지 않아야 한다. 고르는 동안에는 짧게, 결과를 받는 순간에는 조금 따뜻하게 쓴다.

## 2. 보이스 — 담백한 음악 친구

**보이스(변하지 않는 성격)**
- 음악을 좋아하는 친구가 옆에서 짧게 말해 주는 느낌.
- 아는 척하지 않고, 부풀리지 않는다.
- 해요체로 쓴다.

**톤(상황마다 달라지는 태도)**
| 상황 | 톤 | 예 |
|---|---|---|
| 곡을 고르는 중 | 짧고 기능적 | "더 좋아하는 곡을 꾹 눌러 골라 주세요" |
| 기다림·로딩 | 차분하게, 무엇을 하는지 | "곡을 불러오고 있어요" |
| 1위 공개·결과 | 절제된 감정 한 번 | "16곡 중 마지막까지 남은 곡이에요" |
| 공유 문구 | 담백한 권유 | "내 1위는 뭘까? 직접 골라 보기" |
| 문제가 생겼을 때 | 사실 + 할 일 | "곡을 불러오지 못했어요. 잠시 후 다시 시도해 주세요" |

## 3. 원칙 (토스 5대 가치 · 8원칙을 우리 식으로)

1. **명확하게** — 한 문장에 한 가지. 무엇이 일어나는지, 무엇을 하면 되는지.
2. **짧게** — 빼도 뜻이 같은 말은 뺀다(잡초 뽑기).
   - "지금 바로 확인해 보세요!" → "확인해 보세요"
3. **친근하게** — 해요체. "~하십시오/~습니다"는 쓰지 않는다.
4. **존중하며** — 겁주거나 몰아붙이지 않는다. 선택은 리스너가 한다.
   - "저장하지 않으면 모든 기록이 사라집니다" → "나가면 지금까지 고른 곡이 저장되지 않아요"
5. **공감은 한 번만** — 결과·공유 순간에만, 한 문장으로.
6. **다음을 예상할 수 있게** — 버튼은 누르면 벌어질 일을 말한다.
7. **말하듯이** — 소리 내어 읽어 걸리면 고친다.
8. **누구나 아는 단어** — 유행어·밈·영어 약어·기술 용어를 쓰지 않는다.

## 4. 쓰지 않는 표현

| 쓰지 않음 | 이유 | 대신 |
|---|---|---|
| 이모지(🎧 ✨ 💖 👇 🔍 🥳 …) | 기기마다 달라 보이고 가벼워 보임 | 없이 쓴다 |
| 느낌표 남발 | 과장된 인상 | 마침표 또는 생략. 축하 한 곳만 허용 |
| 정성껏 · 아름다운 · 멋진 · 완벽한 · 소중한 · 선명한 · 증폭 · 개성 넘치는 | 꾸밈말이 뜻을 흐림 | 사실을 말한다 |
| 진정한 취향 · 단 한 곡 · 모든 것 | 부풀림 | 구체적인 숫자·대상 |
| 디깅 · 싱크로율 · 구워보기 | 유행어·조어가 섞임 | 파헤치기 → 살펴보기, 싱크로율 → 겹치는 정도(취향 싱크는 기능명으로만) |
| 확인 · 제출 · 다음(단독 CTA) | 결과가 안 보임 | "취향표 보기", "등록 신청하기" |
| 원문 에러(`err.message`), 코드 | 리스너가 할 일이 없음 | 설명 + 할 일 |
| `...` | 표기 혼재 | `…` |

## 5. 용어 사전

| 개념 | 쓴다 | 쓰지 않는다 |
|---|---|---|
| 결과물 | **취향표** | 취향 기록표 · 취향 리스트 · Sort 기록 · 랭킹 · 명곡 순위 |
| 곡의 순서를 정하는 일(동사) | **소트하다** — "{아티스트}의 곡을 소트해볼까요?", "모든 곡을 소트해보세요", "같은 곡으로 소트하면" | 줄 세우다 · 정렬하다 · 나열하다 · 순위를 매기다 |
| 활동 | **월드컵** — "월드컵 시작하기", "월드컵을 그만둘까요?", "취향 월드컵" / 모드 이름 **최애 곡 소트하기** · **같이 소트하기** · ~~믹스 매치 월드컵~~(**현재 미노출**, 아래 격리 항목) | 배틀 · 믹스매치 · 음악 취향 테스트. "토너먼트"는 방식을 설명할 때만 쓴다(홈 모드 소개 "토너먼트로 최애곡을 찾아보세요", 2026-09-21 결정) |
| 개인 공간 | **내 취향 스페이스** | 내 보관함 · 마이 · 저장소 |
| 공개 공간 | **우리의 취향 아카이브** | 공개 취향 아카이브 · 피드 |
| 곡 | **곡** | 트랙 · 명곡 |
| 사람 | **리스너**(다른 사람을 가리킬 때) | 유저 · 이용자 · 친구(친구 관계가 없음) |
| 멈춘 월드컵 | **진행 중인 월드컵** · **이어서 진행하기** · **이어서 하기** | 진행 내역 · 진행 상황 · 초안 |
| 모르는 곡 | **들어볼 곡** | 모르는 곡 목록 |
| 비슷한 사람 | **취향 메이트** · 겹치는 정도는 **취향 싱크** | 싱크로율 |

- **브랜드 동사 "소트하다"를 민다 — 단, 뜻이 같은 자리에만.** 서비스 이름이 Sortify 이므로 "줄 세우다·정렬하다·나열하다"처럼 **곡의 순서를 정한다**는 뜻으로 쓰던 말은 "소트하다"로 쓴다. "월드컵", "이어서 진행하기"처럼 뜻이 다른 말은 소트로 바꾸지 않는다(2026-09-21 결정).
  - 표기: "소트해볼까요", "소트해보세요"처럼 붙여 쓴다. 기능명은 "같이 소트하기".
  - 바꿔 쓰는 기준: 원래 문장의 동사를 "순서를 정하다"로 바꿔도 말이 되면 소트, 아니면 그대로 둔다.
  - 아티스트 한 명 모드의 이름도 **최애 곡 소트하기**다(2026-09-21, 이전 이름 "최애 곡 줄 세우기"). 이미 공유된 이미지에는 옛 이름이 남아 있다.
  - **격리 중(2026-09-21~, 태그 `mix-match-off`): 믹스 매치 월드컵.** 사용자 진입점과 목록에서 내렸다(`src/config/modes.ts` 의 `MIX_MATCH`, docs/mode-pivot.md). 이 문서의 모드 이름·문구("믹스 매치 월드컵", 홈 카드 설명 "좋아하는 아티스트들의 곡을 한데 모아, 토너먼트로 최애곡을 찾아보세요.", 배지 "여러 아티스트")는 **지우지 않고 그대로 둔다.** 플래그를 켜면 그대로 쓴다. 그동안 새 화면 문구에서는 두 모드를 나란히 언급하지 않는다.
  - 활동 이름은 **월드컵**, 결과물은 **취향표**다("소트 기록"이라고 쓰지 않는다).
  - 영문은 `sort` 를 동사로 쓴다: "Sort songs by …?", "sort all of their tracks".
- 앱 이름(Sortify)은 공유 문구에서만 쓴다.
- 영문 모드는 같은 개념을 `taste card` · `World Cup` · `My Taste Space` · `Our Taste Archive` · `song` · `listener` 로 쓴다. 문장형 대소문자(sentence case)를 쓴다.

## 6. 상황별 규칙

### 버튼(CTA)
- 누르면 생기는 결과를 동사로 쓴다: "취향표 보기", "이미지로 저장", "다시 불러오기".
- 두 버튼이 나란하면 주 버튼은 행동, 보조 버튼은 "취소" 또는 되돌아가는 곳을 쓴다.
- 파괴적 행동은 대상을 쓴다: "이 취향표 삭제".

### 빈 상태
- 없는 이유 + 다음 행동을 쓴다. 필요하면 버튼 하나를 둔다.
- "아직 들어볼 곡이 없어요" + "월드컵에서 모르는 곡을 위로 올려 빼면 여기에 모여요."

### 에러 (3단계)
1. **막을 수 있으면 막는다** — 버튼을 비활성화하고 입력 조건을 미리 알린다.
2. **무엇이 일어났는지** 리스너 입장에서 쓴다 — "곡을 불러오지 못했어요".
3. **할 일**을 쓰고, 가능하면 버튼을 준다 — "잠시 후 다시 시도해 주세요" · [다시 불러오기].

| 쓰지 않음 | 씀 |
|---|---|
| 로그인 중 오류가 발생했어요: invalid_grant | 로그인하지 못했어요. 다시 시도해 주세요. |
| 상위 창을 찾을 수 없거나 세션이 만료되었어요. | 로그인 창이 닫혔어요. 처음부터 다시 로그인해 주세요. |
| 복사하지 못했어요. (Permission denied) | 복사하지 못했어요. 공유 창에서 '복사'를 눌러 주세요. |

### 토스트
- 한 줄, 결과를 과거형으로 쓴다: "취향표를 저장했어요", "TOP 10 과 링크를 복사했어요".
- 사실과 다르게 쓰지 않는다(링크와 목록을 복사했다면 둘 다 말한다).

### 확인 창
- 제목은 질문 한 줄: "취향표를 삭제할까요?"
- 설명은 결과 한 줄: "삭제하면 되돌릴 수 없어요."
- 버튼은 행동: [취소] [삭제].

### 메타데이터(검색·공유 미리보기)
- 서술형으로, 과장 없이, 느낌표 없이 쓴다: "좋아하는 아티스트의 곡을 둘씩 골라 나만의 순위를 만드는 음악 취향표 서비스예요."

## 7. 줄바꿈

- 한 덩어리는 **최대 2줄**, 한 줄 약 22자(모바일 13–15px)를 넘기면 의미 단위에서 끊는다.
- 끊는 위치는 **말이 쉬는 곳**(쉼표·"~하고"·"~면" 뒤)이다. 조사 앞이나 단어 중간에서 끊지 않는다.
- 안내 문단은 `\n` + `whitespace-pre-line` 으로 끊는다. 짧은 문장은 `break-keep` 에 맡긴다.
- 괄호 속 보조 설명은 줄을 바꾸기보다 문장 밖으로 뺀다.
