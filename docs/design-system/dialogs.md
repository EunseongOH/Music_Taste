# Sortify 확인 창 · 시트 · 토스트

> 2026-09-21 제정 · 짝 문서: `color.md`(버튼·색), `typography.md`, `ux-writing.md`(문구)
> 컴포넌트: `src/components/space/SpaceUI.tsx` 의 `Sheet` · `ConfirmSheet` · `Toast`

## 1. 무엇을 띄울지 — 세 가지 중 하나

| 형태 | 언제 | 이유 |
|---|---|---|
| **하단 시트** (`Sheet`) | 리스너가 **방금 누른 행동의 연장선**에서 고르는 선택지. 나가기, 이어서 하기/새로 시작, 저장·공유 방식, 삭제 확인, 다음 단계로 넘어가기 전 확인 | 엄지가 닿는 곳에 버튼이 온다. 바깥을 누르면 닫히고, 닫힘은 항상 "아무 일도 일어나지 않음"이다 |
| **중앙 팝업** | ① **입력이 있는 창**(로그인, 미발매곡 등록, 저장 이름 입력) — 키보드가 올라오면 하단 시트는 가려진다. ② **리스너가 시작하지 않은 중단**(음악 정보를 불러오지 못함, 로그인 만료). ③ **읽고 따라 하는 안내**(인스타그램 공유 방법) | 화면 한가운데를 차지해 흐름을 멈춘다. 멈출 이유가 있을 때만 쓴다 |
| **토스트** (`Toast`) | **고를 것이 없는 알림.** 저장했어요, 복사했어요, 곡을 4개 이상 골라 주세요 | 확인 버튼 하나뿐인 창은 누르는 수고만 늘린다 |

판단 순서: 고를 것이 없다 → 토스트. 입력이 있거나 시스템이 끼어든 것이다 → 팝업. 그 밖은 전부 하단 시트.

## 2. 하단 시트 규칙

- 제목 `type-title-1`, 질문 한 줄. 설명 `type-sub text-navy/70`, 최대 2줄.
- 버튼은 세로로: **주 행동(`primaryButton`) → 다른 길(`secondaryButton`) → 잃는 행동(`dangerButton`) → 머무르기(`textLink`)**. 한 시트에 버튼은 셋까지, 그 밖은 글자 링크.
- "머무르기"는 항상 글자 링크다. 바깥 탭·닫기(X)·Esc 와 같은 일을 한다.
- 장식 그림(회전 LP, 트로피, 경고 아이콘)을 넣지 않는다. 정보가 있는 그림(고른 아티스트의 사진)은 제목 위에 둘 수 있다.
- 단계를 나눈 마법사(1단계 → 2단계)는 쓰지 않는다. 선택지를 한 시트에 편다.

## 3. 나가기 흐름 — 만들기 단계 공통

만들기 흐름은 홈 → 아티스트 고르기 → 곡 고르기 → 월드컵 → 취향표다. 어느 단계든 **나가면 홈으로 간다.** 이전 단계로 되돌아가는 길은 시트 안의 버튼으로만 둔다.

| 단계 | 뒤로가기를 누르면 | 시트의 선택지 | 브라우저 뒤로가기 |
|---|---|---|---|
| 아티스트 고르기 | 고른 아티스트가 있으면 시트, 없으면 바로 뒤로 | 저장하고 나가기 · 저장하지 않고 나가기 · 계속 고르기 | 가로채지 않는다 (선택은 자동 저장된다) |
| 곡 고르기 | 시트 | 저장하고 나가기 · **아티스트 다시 고르기** · 저장하지 않고 나가기 · 계속 고르기 | 가로채지 않는다 |
| 월드컵 | 시트 | 임시저장하고 나가기(24시간) · 저장하지 않고 나가기 · 계속하기 | **가로챈다** — 한 판이 길고 되돌릴 수 없다 |
| 취향표 | 저장하지 않았으면 시트 | (로그인 전) 로그인하고 저장하기 · 저장하지 않고 나가기 / (로그인 후) `ConfirmSheet` | 가로채지 않는다 |
| 어느 화면이든, 로그인 전 | `BackButton` 시트 | 로그인하고 저장하기 · 돌아가기 · 머무르기 | — |

월드컵에서 곡 고르기로 되돌아가는 길은 두지 않는다. 되돌아가면 새 판을 시작하기 쉽고, 새 판의 임시저장이 이전 판을 덮는다. 곡을 바꾸고 싶으면 홈에서 새로 시작한다.

홈에서 시작하기를 눌렀는데 진행 중인 월드컵이 있으면 시트로 묻는다: **이어서 하기**(주) · **새로 시작**(잃는 행동). 플레이 중이던 판이면 설명에 라운드와 남은 보관 시간을 쓴다.

### 격리 중인 흐름 — 믹스 매치 월드컵 (2026-09-21~)

믹스 매치(장르 고르기 → 여러 아티스트 고르기 → 곡 고르기 → 월드컵)는 사용자 진입점과 목록에서 내렸다(`MIX_MATCH`, docs/mode-pivot.md). 위 표는 **두 모드 공통**으로 적혀 있고 지금은 한 아티스트 모드에만 적용된다.

- 아티스트 고르기의 "고른 아티스트가 있으면 시트" 규칙은 여러 명을 고르는 믹스 매치에서 의미가 크다. 한 아티스트 모드는 한 명을 누르면 바로 확인 시트("{아티스트}의 곡을 소트해볼까요?")로 간다.
- 홈의 "진행 중인 월드컵이 있어요" 시트, 프로필 창의 "진행 중인 월드컵" 목록은 믹스 매치 초안을 보여 주지 않는다. 취향표 목록도 같다.
- **되살릴 때**: 코드는 모드 분기를 그대로 갖고 있으므로 이 문서에서 고칠 것은 이 절을 지우는 것뿐이다. 장르 고르기 화면(`/genres`)의 나가기는 그때 위 표에 한 줄 추가한다(지금은 확인 없이 뒤로 간다).

## 4. 적용 현황

| 창 | 이전 | 지금 |
|---|---|---|
| 월드컵 나가기 | 없음 | 시트 (2026-09-21) |
| 홈 "새로 시작할까요?" | 카드 팝업 + 트로피 | 시트: 이어서 하기 · 새로 시작 |
| 아티스트 고르기 나가기 | 카드 팝업 + 회전 LP | 시트 |
| 한 아티스트 확인("곡들을 소트해볼까요?") | 카드 팝업 | 시트, 아티스트 사진 유지. 문구를 용어 사전에 맞춤 |
| 곡 고르기 나가기 (2단계 마법사) | 카드 팝업 2단계 + 회전 LP | 시트 하나 |
| 곡 고르기 "확인해 주세요" 알림 | 카드 팝업 + 깜빡이는 경고 | 토스트 |
| `BackButton` 로그인 전 경고 | 카드 팝업 | 시트 |
| 취향표 로그인 전 나가기 | 카드 팝업 + 보관함 아이콘 | 시트 |
| 취향표 덮어쓰기(이름 입력) | 카드 팝업, **취소가 빨강** | 팝업 유지(입력). 취소를 보조 버튼 색으로 |
| 의견·곡 정보 오류 제보 창 (`FeedbackModal`) | 신규 (2026-09-22) | 폼이라 팝업. `bg-cream`, `type-*` 토큰, `primaryButton`, 필수 표시 `text-point-ink`, 오류 `danger`, 장식 아이콘 없음, 결과는 토스트 (76665b8) |
